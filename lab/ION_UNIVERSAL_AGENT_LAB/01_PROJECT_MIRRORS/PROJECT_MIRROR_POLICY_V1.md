# PROJECT MIRROR POLICY V1

Mirrors are evidence projections, never a second source of truth.

Allowed sources: ECOM OS canonical reports/contracts/registries, Knowledge Lab/IWE READONLY projections, governed runtime docs, approved GitHub branch content.

Every mirrored packet records source path, source SHA when available, capture time, read mode, owner, freshness and conflict status.

No mirror writes back to source. Conflicts are reported to Coordinator.
