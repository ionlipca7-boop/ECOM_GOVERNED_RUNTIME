# ecom-cross-model-review

Purpose: obtain an independent second opinion without giving the reviewer write authority.

## Inputs
- exact task/spec
- candidate diff or artifact
- screen/workflow contracts
- evidence bundle

## Reviewer rules
- READONLY
- challenge assumptions
- search for omitted states, regressions, unsafe semantics, duplicate controls and owner violations
- distinguish factual defects from stylistic preferences

## Output
AGREE / DISAGREE / PARTIAL plus independently found defects and severity.
No implementation action is authorized by this review alone.
