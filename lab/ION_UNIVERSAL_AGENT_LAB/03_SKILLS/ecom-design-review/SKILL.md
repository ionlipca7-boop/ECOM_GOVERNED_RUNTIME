# ecom-design-review

Purpose: inspect a built UI candidate for professional quality while preserving project logic.

## Review dimensions
hierarchy, spacing, density, typography, consistency, affordance, state clarity, error prevention, responsive quality, accessibility, operator efficiency.

## Rules
- compare against SCREEN_CONTRACT and workflow map
- distinguish cosmetic preference from semantic defect
- reject visual improvements that add steps or hide required state
- produce before/after defect evidence
- repair only inside LAB candidate scope when separately authorized
- production remains untouched
